# Hemanth Kumar Manga — Portfolio Website

A responsive static portfolio built with HTML, CSS and JavaScript. Project source-code buttons point to the two GitHub repositories currently associated with this portfolio:

- J.A.R.V.I.S Personal AI Assistant: https://github.com/Hemanth-CodeCrafter/Project-AI-Assistant
- SalesAgents AI — LAP Qualification Voice Agent: https://github.com/Hemanth-CodeCrafter/SalesAgents-AI-LAP-voice-agent

## Files

- `index.html` — page structure and portfolio content
- `styles.css` — responsive styles and project illustrations
- `script.js` — mobile navigation and dynamic footer year
- `assets/HemanthResume.pdf` — downloadable resume

## Preview locally

Open `index.html` in a browser. For a local web server, run `python -m http.server 8000` from this directory and visit `http://localhost:8000`.

## Publish using GitHub Pages

1. Create a **new, separate public repository** named `portfolio` under `Hemanth-CodeCrafter`. Do not use `Project-AI-Assistant` for the portfolio website.
2. Upload the contents of this folder to the root of the new repository, keeping the `assets` folder.
3. Open the new repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then save.
5. After GitHub Pages finishes deploying, the expected URL is `https://hemanth-codecrafter.github.io/portfolio/`.

If you choose a different repository name, the published URL will use that name instead of `portfolio`.
